# 🌷 Tuliptopia

My first website project from the **CodePath Intro to Web Development** course! It's a page for a made-up spring tulip festival.

**Check it out:** https://diyapatelz.github.io/TulipTopia/

## What is this?

Tuliptopia is a festival where you walk around a field of tulips, pick your own bouquet, grab food from food trucks, and have a picnic at sunset. Obviously it's not a real event, but I wanted to make the site look like one.

## What's on it

- An About section, a Schedule section, and an RSVP section
- A dark mode button (my favorite part)
- A "Reduce Motion" button for people who don't want animations
- An RSVP form where you put in your name, email, and state. A thank-you popup shows up when you submit.
- Photos for each activity (basket picking, food trucks, picnic)

## What I used

- HTML
- CSS
- JavaScript
- GitHub Pages to put it online

## What I learned

- How to structure a page with HTML and style it with CSS
- How to use JavaScript to make buttons and forms actually do things
- How to put a site on GitHub Pages (images broke at first because I put them in the wrong folder 😅)

## Run it yourself

1. Download this repo
2. Open `index.html` in your browser
